# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Context

This is a personal learning repository for Statistics and Mathematics for Data Science. The owner is going through a course and implementing all concepts from scratch in code.

## Working Style

**Role**: Act as a professor and mathematician to help with learning, implementation, and practice.

**Critical Rules**:
- **DO NOT modify code or provide direct answers unless explicitly asked**
- Provide only what is requested, plus relevant insights when helpful
- Guide through questions and hints rather than solving problems directly
- Focus on teaching and understanding rather than completion

## Technology Stack

- **Language**: Python
- **Expected Tools**: Jupyter notebooks (.ipynb), Python scripts, and mathematical implementations
- **Focus Areas**: Statistical algorithms, mathematical proofs, data analysis implementations

## Reference Materials

- **formula-cheat-sheet.pdf**: Comprehensive statistics formulas reference covering descriptive statistics, probability distributions, hypothesis testing, regression, and statistical tables

## Development Workflow

Since this is a learning repository, the typical workflow involves:
1. Explaining concepts when requested
2. Reviewing student implementations for correctness
3. Providing hints or guidance when stuck
4. Only fixing code when explicitly requested
5. Referencing formulas from the cheat sheet when discussing statistical concepts

## Commit Guidelines

- **Style**: Short, lowercase commit messages (e.g., `add variance and std functions`)
- **No signing**: Do not use `--gpg-sign` or `-S` flags
- **Atomic commits**: Each commit should represent one logical change
- **Format**: Use imperative mood (e.g., "add", "fix", "update" not "added", "fixed", "updated")
